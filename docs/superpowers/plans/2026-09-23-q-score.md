## 1. 已确认设计

场景：论文已完成解析/索引，用户针对单篇论文进行单轮问答。比较全文直投、PaperMind、cosine、Jaccard、BM25，以及仓库已有其他 RAG 方法。共同使用官方 deepseek-flash，最终生成参数、问题、原文、回答指令保持一致；全文基线不受 RAG 检索上下文预算限制。

公式（先聚合组件，再计算 Q，不平均逐题 Q）：

```text
Q = 100 × (F / F_ref)^wF
        × (TTFT_P50_ref / TTFT_P50)^w50
        × (TTFT_P95_ref / TTFT_P95)^w95
wF = 0.6, w50 = 0.2, w95 = 0.2
```

- `F`：全体执行问题的 Answer F1 均值，取值 [0, 1]；明确记录的执行失败计零。不可把无记录当成明确失败。
- `ref`：显式指定的一份同协议全文直投结果，不是所有参评方法的最优值，也不是理论质量上限。有效基线自身 Q=100，其他方法可超过 100。
- TTFT：从在线问题处理开始，到首段用户可见答案内容；包含在线检索、上下文组装、排队、网络及重试等待，不包含预先解析/建索引，也不把 reasoning、usage、role 事件当成答案。
- P50/P95 使用已有速度聚合的分位数实现，单位毫秒。两者相关但含义不同：典型等待与尾部等待；总速度权重为 0.4，不宣称三项统计独立。
- 不设秒数门槛、满意度常数、额外质量底线或 epsilon。不使用候选集 min-max 归一化。
- 所有权重有限且严格大于零，总和与 1 的差不超过 1e-9；非法配置报错，不静默重归一化。第一版暂不支持用零权重删除指标。
- 候选 F=0 且其余数据有效时 Q=0；基线 F=0、任意 TTFT 非正/缺失/非有限、空样本或协议不匹配时 Q=null，并记录原因。
- 权重改动仅需离线重算，不需要再次调用模型；保存每次使用的配置快照及基线文件 SHA-256。

已落盘配置：`bench/configs/scoring/q-score.json`。使用 scoring 子目录，避免与检索配置矩阵混淆；本次仅保存配置与计划，尚未接入运行时。

## 2. 公平性前置条件与边界

当前代码的三个问题不能靠 Q 公式消除，实施时必须先修正或明确拒绝评分：

1. `answerF1` 当前是稀疏观测聚合，无答案题单独评拒答。新增 `answerF1AllQuestions` 与独立版本，不静默改变旧字段含义。QASPER 的 yes/no、多段抽取答案、无答案标注必须正确归一化。
2. 全文和 RAG 的生成上限、在线计时起点必须相同口径；实际请求参数需写入可比较契约。模型名相同不足以证明参数相同。
3. TTFT 不得只挑各方法不同的成功子集比较。第一版保留 `speedComparisonIssues` 对完成题集合一致的限制，集合不同则 Q=null；仍展示失败率和原始速度。失败没有首 token 时不填超时值作为 TTFT。这个保守规则不等于设置等待预算。

继续保留：Answer F1 各口径与分母、拒答指标、judge（启用时）、检索指标、逐题 TTFT、P50/P95、完整回答延迟、tokens、各阶段状态、错误、建索引成本。缺失指标显式表达不可用，不伪造零值。全文不参与检索排名，但可以参与 Q 比较。

同一主表使用仓库冻结的 60 篇/179 题切片；其他规模单列。每批固定全文参考结果，同步冻结模型、参数与采样协议；不跨运行环境或服务配置比较 Q。单轮远程 API 时延仍有噪声，Q 不能代替组件数据和重复实验。

- [ ] 新建 `qScore.ts`。公开 `QComponents` 三字段均为 number，`QConfig` 使用配置 JSON 的字面量字段与三个 number 权重；`parseQConfig(value: unknown): QConfig` 校验对象结构、公式版本、baselineMode、三个权重与总和，返回显式复制的配置。计算按以下主体实现，输入校验失败抛 Error：

```ts
export function calculateQ(value: QComponents, ref: QComponents, config: QConfig): number {
  const { weights: w } = parseQConfig(config)
  for (const item of [value, ref]) {
    if (!Number.isFinite(item.answerF1) || item.answerF1 < 0 || item.answerF1 > 1)
      throw new Error('answerF1 must be finite and within [0, 1]')
    for (const t of [item.ttftP50, item.ttftP95]) {
      if (!Number.isFinite(t) || t <= 0) throw new Error('TTFT must be finite and positive')
    }
    if (item.ttftP95 < item.ttftP50) throw new Error('P95 must not be below P50')
  }
  if (ref.answerF1 === 0) throw new Error('reference answerF1 must be positive')
  if (value.answerF1 === 0) return 0
  const exponent = w.answerF1 * (Math.log(value.answerF1) - Math.log(ref.answerF1))
    + w.ttftP50 * (Math.log(ref.ttftP50) - Math.log(value.ttftP50))
    + w.ttftP95 * (Math.log(ref.ttftP95) - Math.log(value.ttftP95))
  const score = 100 * Math.exp(exponent)
  if (!Number.isFinite(score)) throw new Error('Q is not finite')
  return score
}
```

```ts
export interface QComponents {
  answerF1: number
  ttftP50: number
  ttftP95: number
}

export interface QConfig {
  schemaVersion: 1
  formula: 'weighted-geometric-relative-v1'
  baselineMode: 'full-context'
  weights: QComponents
}

function object(value: unknown): Record<string, unknown> {
  if (typeof value !== 'object' || value === null || Array.isArray(value)) {
    throw new Error('Q config must contain objects')
  }
  return value as Record<string, unknown>
}

export function parseQConfig(value: unknown): QConfig {
  const raw = object(value)
  if (raw.schemaVersion !== 1 || raw.formula !== 'weighted-geometric-relative-v1'
    || raw.baselineMode !== 'full-context') throw new Error('unsupported Q configuration')
  const weights = object(raw.weights)
  const keys = ['answerF1', 'ttftP50', 'ttftP95'] as const
  if (Object.keys(weights).length !== keys.length) throw new Error('unexpected Q weight keys')
  for (const key of keys) {
    const n = weights[key]
    if (typeof n !== 'number' || !Number.isFinite(n) || n <= 0) {
      throw new Error(`invalid Q weight: ${key}`)
    }
  }
  const parsed = {
    answerF1: weights.answerF1 as number,
    ttftP50: weights.ttftP50 as number,
    ttftP95: weights.ttftP95 as number,
  }
  if (Math.abs(parsed.answerF1 + parsed.ttftP50 + parsed.ttftP95 - 1) > 1e-9) {
    throw new Error('Q weights must sum to one')
  }
  return {
    schemaVersion: 1, formula: 'weighted-geometric-relative-v1',
    baselineMode: 'full-context', weights: parsed,
  }
}
```

```ts
export interface QasperAnswerAnnotation {
  unanswerable?: boolean
  extractive_spans?: readonly string[]
  free_form_answer?: string
  yes_no?: boolean | null
}

export function qasperReference(answer: QasperAnswerAnnotation): string {
  if (answer.unanswerable) return 'Unanswerable'
  if (answer.extractive_spans?.length) return answer.extractive_spans.join(', ')
  if (answer.free_form_answer?.trim()) return answer.free_form_answer
  if (typeof answer.yes_no === 'boolean') return answer.yes_no ? 'Yes' : 'No'
  throw new Error('QASPER annotation contains no answer')
}

function tokens(text: string): string[] {
  const normalized = text.toLowerCase()
    .replace(/[\x21-\x2f\x3a-\x40\x5b-\x60\x7b-\x7e]/g, '')
    .replace(/\b(a|an|the)\b/g, ' ')
    .trim()
  return normalized ? normalized.split(/\s+/) : []
}

export function qasperAnswerF1(answer: string, references: readonly string[]): number {
  if (!references.length || references.some(ref => typeof ref !== 'string' || !ref.trim())) {
    throw new Error('missing QASPER references')
  }
  const predicted = tokens(answer)
  return Math.max(...references.map(reference => {
    const gold = tokens(reference)
    if (!predicted.length || !gold.length) return 0
    const counts = new Map<string, number>()
    for (const token of gold) counts.set(token, (counts.get(token) ?? 0) + 1)
    let overlap = 0
    for (const token of predicted) {
      const remaining = counts.get(token) ?? 0
      if (remaining > 0) {
        overlap++
        counts.set(token, remaining - 1)
      }
    }
    return 2 * overlap / (predicted.length + gold.length)
  }))
}
```

```ts
import type { PerSampleRecord, QaQuestion } from '../types'
import { qasperAnswerF1 } from './qasperQuality'

export const QA_QUALITY_DEFINITION = 'qasper-all-questions-v1' as const

export function aggregateQaQuality(records: PerSampleRecord[], expectedIds: string[]) {
  const expected = new Set(expectedIds)
  if (!expected.size || expected.size !== expectedIds.length) throw new Error('invalid QA cohort')
  const seen = new Set<string>()
  let sum = 0
  let completed = 0
  for (const row of records) {
    if (!expected.has(row.id) || seen.has(row.id)) throw new Error('unexpected or duplicate QA record')
    seen.add(row.id)
    const score = row.metrics.answerF1AllQuestions
    if (!Number.isFinite(score) || score < 0 || score > 1) throw new Error('invalid QA F1')
    if (row.generationStatus === 'completed') completed++
    else if (row.generationStatus === 'failed' || row.generationStatus === 'skipped') {
      if (score !== 0) throw new Error('failed QA must score zero')
    } else throw new Error('unknown QA generation status')
    sum += score
  }
  if (seen.size !== expected.size) throw new Error('missing QA record')
  return {
    answerF1AllQuestions: sum / expected.size,
    answerF1AllQuestionsSampleCount: expected.size,
    qaCompletionRate: completed / expected.size,
  }
}

export function finalizeQaQuality(records: PerSampleRecord[], questions: QaQuestion[]) {
  const byId = new Map(questions.map(q => [q.id, q]))
  if (byId.size !== questions.length) throw new Error('duplicate QA question')
  for (const row of records) {
    const question = byId.get(row.id)
    if (!question || question.qualityDefinition !== QA_QUALITY_DEFINITION
      || !question.qualityAnswers?.length) throw new Error('missing versioned QA references')
    row.referenceAnswers = [...question.qualityAnswers]
    if (row.generationStatus === 'completed') {
      if (typeof row.answer !== 'string') throw new Error('completed QA missing answer')
      row.metrics.answerF1AllQuestions = qasperAnswerF1(row.answer, row.referenceAnswers)
    } else if (row.generationStatus === 'failed' || row.generationStatus === 'skipped') {
      row.metrics.answerF1AllQuestions = 0
    } else throw new Error('unknown QA generation status')
  }
  const ids = questions.map(q => q.id)
  return {
    metrics: aggregateQaQuality(records, ids),
    meta: { qaQualityDefinition: QA_QUALITY_DEFINITION, qaExpectedQuestionIds: ids },
  }
}
```

```ts
  }
  if (result.meta.speedMetricSchemaVersion !== 2 || result.meta.speedDefinition !== 'query-timeline-v2'
    || result.meta.streaming !== true || result.meta.llmCacheEnabled !== false
    || result.meta.queryConcurrency !== 1) throw new Error('unsupported Q speed contract')
  const ids = result.meta.qaExpectedQuestionIds
  if (!ids || ids.length !== result.meta.total
    || questionIdsHash(ids) !== result.meta.executedQuestionIdsHash) throw new Error('invalid Q cohort')
  for (const row of result.perSample) {
    if (!row.referenceAnswers?.length) throw new Error('missing reference snapshot')
    if (row.generationStatus === 'completed') {
      if (typeof row.answer !== 'string') throw new Error('missing answer snapshot')
      const recomputed = qasperAnswerF1(row.answer, row.referenceAnswers)
      if (Math.abs(recomputed - row.metrics.answerF1AllQuestions) > 1e-12) {
        throw new Error('per-question quality mismatch')
      }
    }
  }
  const quality = aggregateQaQuality(result.perSample, ids)
  const options = { evidenceRequired: result.meta.mode !== 'full-context' }
  const eligible = result.perSample.filter(row => row.generationStatus === 'completed')
  const speed = aggregateSpeedMetrics(eligible, options)
  const meta = speedContractMeta(result.meta as SpeedRunContract, eligible, options)
  if (meta.completedSpeedQuestionIdsHash !== result.meta.completedSpeedQuestionIdsHash
    || meta.completedSpeedQuestionCount !== result.meta.completedSpeedQuestionCount) {
    throw new Error('completed speed cohort mismatch')
  }
  for (const [key, value] of Object.entries({ ...quality, ...speed })) {
    if (!Number.isFinite(result.metrics[key]) || Math.abs(result.metrics[key] - value) > 1e-9) {
      throw new Error(`aggregate mismatch: ${key}`)
    }
  }
  if (!speed.speedSampleCount) throw new Error('empty speed cohort')
  return {
    answerF1: quality.answerF1AllQuestions,
    ttftP50: speed.timeToFirstTokenP50Ms,
    ttftP95: speed.timeToFirstTokenP95Ms,
  }
}

export function buildQComparison(reference: BenchResult, candidate: BenchResult, input: QConfig): QComparison {
  const config = parseQConfig(input)
  const result: QComparison = {
    schemaVersion: 1, config, score: null, reasons: [], reference: null, candidate: null,
  }
  if (reference.meta.mode !== 'full-context') result.reasons.push('reference must be full-context')
  for (const [label, source] of [['reference', reference], ['candidate', candidate]] as const) {
    try { result[label] = components(source) }
    catch (error) { result.reasons.push(`${label}: ${error instanceof Error ? error.message : String(error)}`) }
  }
  result.reasons.push(...speedComparisonIssues(reference, candidate))
  const refs = (source: BenchResult) => {
    const byId = new Map(source.perSample.map(row => [row.id, row.referenceAnswers]))
    return JSON.stringify(source.meta.qaExpectedQuestionIds?.map(id => [id, byId.get(id)]))
  }
  if (refs(reference) !== refs(candidate)) result.reasons.push('reference snapshots differ')
  if (!result.reasons.length && result.reference && result.candidate) {
    try { result.score = calculateQ(result.candidate, result.reference, config) }
    catch (error) { result.reasons.push(error instanceof Error ? error.message : String(error)) }
  }
  return result
}
```

```ts
import { createHash } from 'node:crypto'
import { readFileSync, writeFileSync } from 'node:fs'
import { basename } from 'node:path'
import type { BenchResult } from '../types'

function isObject(value: unknown): value is Record<string, unknown> {
  return value !== null && typeof value === 'object' && !Array.isArray(value)
}

export function readBenchResult(value: unknown): BenchResult {
  if (!isObject(value) || !isObject(value.meta) || !isObject(value.config)
    || !isObject(value.metrics) || !Array.isArray(value.perSample)
    || !Array.isArray(value.errors) || typeof value.config.name !== 'string'
    || (value.task !== 'qa' && value.task !== 'summary')) {
    throw new Error('invalid benchmark result envelope')
  }
  for (const row of value.perSample) {
    if (!isObject(row) || typeof row.id !== 'string' || !isObject(row.metrics)) {
      throw new Error('invalid benchmark sample envelope')
    }
  }
  return value as unknown as BenchResult
}

function assertNoCredentialFields(value: unknown): void {
  if (Array.isArray(value)) {
    for (const item of value) assertNoCredentialFields(item)
  } else if (isObject(value)) {
    for (const [key, item] of Object.entries(value)) {
      if (/^(api[_-]?key|authorization|access[_-]?token|secret|password)$/i.test(key)) {
        throw new Error('credential field detected; export refused')
      }
      assertNoCredentialFields(item)
    }
  }
}

export function readQSource(path: string) {
  const bytes = readFileSync(path)
  return {
    name: basename(path),
    sha256: createHash('sha256').update(bytes).digest('hex'),
    data: JSON.parse(bytes.toString('utf8')) as unknown,
  }
}

export function writeQArtifact(path: string, artifact: unknown): void {
  assertNoCredentialFields(artifact)
  writeFileSync(path, JSON.stringify(artifact, null, 2) + '\n', { flag: 'wx' })
}
```

父目录不存在时给出 ENOENT 并保留原文件，不自动创建任意层级目录。EEXIST 提示选择新文件名。不需要 `--force`，不做自动覆盖。输入含未知字段时保留其 JSON 数据，不能以重建 BenchResult 的方式丢失原始指标；可选字段包含凭据的外部文件拒绝导出，错误中不回显凭据值。
