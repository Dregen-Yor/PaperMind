# PaperMind E-k5 产品接入

用户授权：在 feat/Ek5 分支交付可 npm run dev 使用的版本，E-k5-hybrid 为唯一论文检索方式。

正常路径保持 PeerQA 评测版行为：原生 PDF outline → 已验证目录页 → 排版标题；精确标题边界组成叶子组；标题全路径向量与路径加正文 BM25 等权 RRF(k=60)；每篇 top-5，相关性排序，组正文完整保留。禁止自动换成旧段落、LLM 路由或全文检索。

产品适配：复用现有 index 表，以 ek5-product-v1 独立版本保存页文本、叶子组、向量与模型身份。旧索引首次提问自动迁移，只有完整构建成功才覆盖；并发同篇合并构建。模型不可用、结构不可识别、空文本、坏索引均有明确失败语义；失败不会在没有论文上下文时继续回答。划选问答与 /abstract 保留。

多篇分别选取 top-5，携带论文标题与来源页码。默认合并上下文上限 120000 字符，可在设置页改为 4000–1000000；超限拒绝发送而非悄悄截断。字符限制是产品资源保护，不等同于提供商 token 上限；历史和输出仍消耗模型上下文。保留现有多轮改写与生成提示词。

设置页移除旧语义树开关及索引 LLM 选择，展示模型状态、上下文上限和本地重建入口。QASPER 与 PeerQA 已冻结结果不改写，产品算法与 bench 通过相同输入逐字对照测试。
