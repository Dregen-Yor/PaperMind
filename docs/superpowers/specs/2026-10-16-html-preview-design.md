# PaperMind HTML 在线预览设计

日期：2026-10-16。状态：设计已在对话中确认，待书面评审；尚未实现。

## 目标与范围

用户可在 PaperMind 输入技术文章的 HTTPS 链接，直接在应用内阅读原网站。预览应保留网站自己的排版、代码块和交互，让阅读技术博客与阅读 PDF 一样不必离开应用窗口。

本次只做**临时的在线网页预览**。不导入 HTML 文件，不抓取或保存网页，不在文献库创建条目，不做离线快照、划选、笔记、问答或索引。离开预览页即关闭该网页视图；再次进入时回到空白输入状态。现有 PDF、知识库、数据库和备份格式不变。

## 已确认的设计选择

- 入口是侧栏中的独立“网页预览”页，不占用现有 PDF 阅读页。
- 使用 Electron `WebContentsView` 实时加载原网站。`iframe` 受网站嵌入策略限制；Electron 当前不推荐为新功能使用 `<webview>`。[Web Embeds](https://www.electronjs.org/docs/latest/tutorial/web-embeds)
- 应用内只加载 HTTPS。网页中的普通链接、站内目录、重定向及请求新窗口的 HTTPS 链接，都继续在同一预览区域打开；不创建网站弹窗。
- 工具栏提供地址输入、后退、前进、刷新和用户主动触发的“在系统浏览器打开”。地址栏随着页面跳转更新。
- 远程网页不获得 PaperMind 的 preload、数据库 API 或 Node 能力；其权限请求默认拒绝。[Electron Security](https://www.electronjs.org/docs/latest/tutorial/security/)

## 页面设计

设计方向是“安静的阅读桌”：应用只提供必要导航，让文章本身占据主要面积。参考当前文献库的纸色与 PDF 阅读器的收窄侧栏，不另造一套浏览器主题。

```text
┌─ 窄侧栏 ─┬────────────────────────────────────────────────┐
│ 文献库   │ 〈 〉  [ https://文章地址…             ]  ↻  外部打开 │
│ 网页预览 │────────────────────────────────────────────────│
│          │                                                │
│          │              原网站完整页面                    │
│          │                                                │
└──────────┴────────────────────────────────────────────────┘
```

- 桌面窗口沿用阅读模式约 72px 的窄侧栏；预览工具栏约 64px 高。地址栏占据剩余宽度，输入后按 Enter 打开；编辑时按 Escape 恢复当前地址。按钮保留可见焦点和明确的辅助技术名称，后退/前进无历史时禁用。
- 预览区域是直角矩形，四周留约 12px 的 `--bg-reader` 底色，边界用一条细线表达。`WebContentsView` 是原生视图，方案不依赖 CSS 圆角裁剪或覆盖在网站之上的浮动控件。
- 色彩复用 `--bg-base` `#f7f5f0`、`--bg-surface` `#fffdf8`、`--bg-reader` `#e8e3d9`、`--text-primary` `#352d26`、`--text-secondary` `#6d6257`、`--accent` `#73543c`。工具栏采用现有 `--font-ui`；仅空态标题使用 `--font-reading`。不改写远程网页的字体、配色或内容宽度。
- 首次进入时聚焦地址栏。空态只显示“粘贴 HTTPS 链接，按 Enter 预览原网页”，不加介绍卡片或装饰插图。加载时在工具栏下显示一条细进度线；不让多个控件同时闪动。
- 宽度不足时先收起“在系统浏览器打开”的文字，保留有标签的图标按钮；约 520px 以下将地址栏和操作按钮排成两行，让 URL 可读且网页区域继续占据其余高度。网页自身响应窄视口，应用不修改网站布局。

## 数据流与职责

1. Vue 路由新增独立预览页。页面管理地址栏、按钮、空态、加载态和错误态，并测量网页占位区域的矩形。它只将打开地址、导航操作和区域尺寸发给主进程，不读取远程 DOM。
2. 主进程为当前应用窗口创建一个 `WebContentsView`，只把它放在占位区域内。窗口缩放、侧栏变化和窄屏工具栏换行时，页面重新上报边界；主进程同步视图尺寸。离开路由或窗口关闭时移除并销毁视图，防止原生层遮挡其他页面。
3. 主进程将当前 URL、后退/前进可用性、加载开始/结束和主框架加载失败事件发回应用页面。页面跳转与同页路由变化均更新地址栏。用户编辑地址时，页面事件不覆盖尚未提交的输入。
4. 不存储 URL、页面正文或浏览历史。视图会话与 PaperMind 的应用页面隔离，使用非持久的网页会话；会话内站点状态可支持本次预览中的正常导航，退出应用后不保留。

预览 IPC 使用独立的 `preview` 接口，不塞入 `window.db`。预计涉及 `src/App.vue`、`src/router/index.ts`、新增预览页面、`electron/main.ts`、预览控制模块、`electron/ipc.ts`、`electron/preload.ts` 和对应的渲染层类型声明。不会修改 `electron/db/schema.ts` 或 `electron/db/index.ts`。

## 导航与安全规则

- 用户输入可去掉首尾空白；没有协议的域名按 `https://` 补全。拒绝无法解析的地址、嵌入凭据的 URL、`http:`、`file:`、`javascript:`、`data:` 及其他非 HTTPS 协议。主进程再次执行相同的协议检查，不能只信任前端校验。
- 所有顶层导航、重定向及新窗口请求都经过主进程检查。允许的 HTTPS 目标在同一视图加载；不允许的目标保持当前页面，并在应用工具栏提示原因。远程页面不可自行打开系统浏览器。
- 远程视图显式关闭 Node 集成，开启上下文隔离与沙箱，不加载 PaperMind preload，不关闭 Chromium 的 web security。预览 IPC 验证消息发送方是本应用窗口；网页会话默认拒绝权限申请和下载。
- “在系统浏览器打开”只响应应用工具栏中的用户操作。对已加载的 HTTPS 页面打开当前地址；对用户手动输入的 HTTP 地址，仅在明确点击该按钮后交给系统浏览器。不会因网页脚本或自动重定向调用 `shell.openExternal`。

这些规则遵循 Electron 对远程内容、权限、导航和外链的安全建议。[Electron Security](https://www.electronjs.org/docs/latest/tutorial/security/)

## 状态与失败反馈

| 场景 | 页面反馈 |
| --- | --- |
| 未输入地址 | 地址栏聚焦；阅读底色上显示简短输入提示 |
| 地址无效或不是 HTTPS | 地址栏保留输入；说明“仅支持 HTTPS 链接”；不创建远程视图 |
| 正在加载 | 地址栏显示目标地址，工具栏下显示细进度线；后退/前进状态仍按当前历史显示 |
| 主页面网络、证书或站点加载失败 | 隐藏失败的原生视图，在预览区域显示可理解的原因，并提供“重试”及“在系统浏览器打开” |
| 网站请求不受支持的跳转、权限或下载 | 保持当前预览；在工具栏显示简短说明，避免无响应感 |
| 网站需要登录、阻止自动化或使用特殊加载流程 | 展示网站自身结果；若无法显示，提供外部打开，不承诺绕过网站限制 |

## 验收与验证

- HTTPS 技术博客能在独立页显示原站内容；站内目录、普通链接、前进/后退、刷新和地址栏同步正常。新窗口 HTTPS 链接保持在同一视图。
- HTTP 与非网页协议不能在预览视图加载；网页脚本不能访问 `window.db`、Node 或应用 IPC，也不能自动打开系统浏览器。
- 输入错误、网络断开、证书错误和不受支持的跳转有明确反馈；用户可重试或主动转去浏览器。
- 在桌面与窄窗口尺寸下，原生视图始终只覆盖网页占位区域；切换路由、关闭窗口后无残留视图。
- 自动测试覆盖 URL 归一化与协议守卫、导航与弹窗拦截、视图生命周期及状态事件；再用具有代码块、目录和客户端脚本的真实技术博客进行手工预览。实施后运行仓库要求的 `npm run typecheck` 和 `npm test`。

## 实施边界

本方案只记录设计与验收标准。当前分支不实现页面或 IPC。后续实现应按已确认的预览范围拟定具体任务，再修改产品代码。
