# PDF 阅读器性能对比（2026-10-16）

## 方法

用 `node scripts/pdf-perf/bench.mjs 3` 在无头 Chromium 中运行实际的 `PdfViewer.vue`。每次新建浏览器配置，打开脚本固定生成的 60 页、150,834 字节 PDF；记录第 1 页完成、跳转第 50 页完成、放大后第 50 页完成，以及已渲染页数。改前和改后使用同一脚本、同一 PDF、同一浏览器环境，各运行三次。时间单位为毫秒。

| 指标 | 改前三次 | 改后三次 | 中位数对比 |
| --- | --- | --- | --- |
| 首屏第 1 页 | 328.7 / 178.3 / 168.5 | 341.2 / 168.6 / 173.4 | 178.3 → 173.4（接近） |
| 跳转第 50 页 | 390.6 / 446.2 / 391.4 | 17.1 / 13.8 / 12.2 | 391.4 → 13.8（约 28.4 倍） |
| 第 50 页放大 | 832.5 / 837.8 / 834.5 | 19.2 / 21.1 / 12.6 | 834.5 → 19.2（约 43.5 倍） |
| 打开后已渲染页数 | 26 / 25 / 26 | 2 / 2 / 2 | 26 → 2 |
| 放大后已渲染页数 | 60 / 60 / 60 | 3 / 3 / 3 | 60 → 3 |

改动包括复用 PDF.js 文档、只渲染视口附近及指定页、释放远离视口的页面。首屏结果受浏览器冷启动波动影响，三次样本只能说明没有稳定的明显改善。跳转与缩放的差异大且三次结果一致。

本基准测的是浏览器中的 Vue/PDF.js 渲染过程。新增的 Electron 本地文件协议用来避免阅读路径上的 base64 IPC 传输，但这里的 PDF 通过 Blob URL 注入，因此以上数字**不包含**该传输改动的耗时，也不代表完整 Electron 应用或大文件实测。
