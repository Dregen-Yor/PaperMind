# Docling 图文摘要配置与验收

## 配置服务

已部署 [docling-serve](https://github.com/docling-project/docling-serve) 于 `xmdjy@101.76.222.151` 的 `127.0.0.1:5001`，提供 `POST /v1/convert/file` 和 `GET /openapi.json`。模型路径、GPU、OCR 和公式模型在服务端配置；PaperMind 仅保存服务根地址和可选 `X-Api-Key`。

打开设置 → Docling 文档解析。默认地址 `http://127.0.0.1:5001` 会让桌面应用自动建立到 `xmdjy@101.76.222.151` 的 SSH 转发，无需手动开隧道，但本机需要可免交互登录 SSH。也可填其他服务根地址（可含反向代理前缀，如 `https://host/docling`，不填写完整转换接口）、可选 Key、30–1800 秒超时（默认 600）、OCR 与公式识别，点击保存和测试连接。测试连接确认接口可用，不等同于模型转换已经通过。

应用以 multipart 上传本地 PDF，请求 JSON、`target_type=inbody`、嵌入图片、2 倍图片尺度和准确表格结构，避免服务端开启素材存储后默认返回下载链接。启用公式识别时发送 `do_formula_enrichment=true`；若服务未安装相应模型，请先关闭公式选项，原文公式区域仍可截图。完整协议见 [官方 REST API](https://docling-project.github.io/docling/usage/api_server/rest_api/)。

## 使用与限制

在当前对话选择 PDF 后输入 `/abstract`。解读使用当前对话模型，按研究问题、贡献、方法、实验和局限组织中文讲解，精选原图、原表和关键公式。图片解释依据图注/正文；模型不接收图片像素，无法可靠解释原文未描述的图内细节。公式识别不可靠时回退原文截图并提示。

单篇论文的 `/abstract` 与阅读页“论文摘要”共用已保存的结果：再次打开摘要页或在另一段对话输入 `/abstract` 时直接显示，不要求 Docling 或模型在线。以前只写入聊天消息的单篇摘要也可从历史对话读取；明确选择“重新生成”或重试时才重新运行。多篇论文的联合 `/abstract` 仍保留在原对话中，不作为某一篇论文的单篇缓存。

提供给模型的证据按类型分别编号，例如 `text-1`、`heading-1`、`picture-1`、`table-1`、`formula-1`。已有 `item-N` 解析缓存会在读取时转换，无需重新上传 PDF；已生成的报告不重写。

图片点击或按 Enter/空格放大；页码点击或键盘激活会定位原文。无图注且位于页面顶部的狭窄页眉图片不会插入报告，同一原图在一篇报告内只展示一次。图表展示只保留“原文图片/原文表格”和页码，完整图注仍作为模型证据使用，不在图片下重复显示。Docling 提取的多行对齐公式会先规范化再交给 KaTeX；混入明显正文长句或无法安全解析时回退原文截图。多篇 PDF 分别生成带标题的解读。长论文分批提炼，不直接裁掉后半篇；证据汇总无法缩短时改为按证据批次分别生成解读。章节提炼或分批解读被输出上限截断会提示提高模型上限。最终解读截断可点击继续；多篇解读保留已完成章节，从中断论文续写，再处理剩余的原选论文。续写位置随消息保存，之后更改所选论文不会改变这一轮解读的范围。

提炼、证据汇总和分批生成的每段有效模型输出都会写入本机 SQLite 检查点。摘要中断后点击重试会复用同一论文内容、提示词、续写上下文和模型配置下的已完成段落；这些条件改变时使用新的检查点，不会误用旧结果。检查点随论文删除或清空数据而清除，不作为历史报告导出。`/abstract` 的单次模型请求最多等待 300 秒；短暂网络错误、超时、429 或指定的服务端错误会自动重试一次。最终失败会显示发生在哪个提炼、汇总或生成阶段。

原图保存在本地 SQLite，以不可变内容 ID 寻址。重新解析不会覆盖旧聊天引用的图片。PDF 字节、解析地址或选项变化会使解析缓存失效；认证 Key 单独变化不会。删除论文或清空数据会清理对应解析和素材，历史消息此时显示原图不可用。

备份包含解析和原图，默认清空 Docling API key；恢复备份后历史摘要仍可展示原图。旧备份未含解析/素材时可以正常导入。服务不可用时，已有有效缓存仍可用于生成（须保留已保存的服务地址和相同解析选项）；历史摘要显示无需服务在线。

## 真实服务联调

1. 保存实际服务地址和可选 Key，测试连接成功。
2. 导入有方法示意图、结果表格、数学公式的测试 PDF；选择当前对话模型后执行 `/abstract`。
3. 核对原图/表格清晰度、原图号、数值与原文一致，公式符号解释有据可查；点击 `[pN]` 应跳到 PDF 对应页。
4. 再次执行摘要，确认不重复上传 PDF；停止 Docling 后用缓存生成仍成功。
5. 重启 PaperMind，打开历史消息，确认原图能加载、放大和跳页。
6. 导出默认备份，检查 `settings.docling_config.apiKey` 为空；在隔离数据目录导入备份，确认原图恢复。不要在工作数据上执行清空或导入验收。
7. 用错误 Key、无法连接地址、较短超时测试失败卡和重试；模型生成失败后解析缓存应保留。
8. 修改 OCR/公式设置后再次摘要应重新解析；再解析前的历史原图仍可用。
